# Human Codex 0.1.0-rc.6 휴대용 회사 테스트판

상태: **회사 내부 개인 사용 테스트 GO / 공개 배포 HOLD**

이 버전은 회사 PC의 샌드박스 사용자 로그온 정책과 충돌하지 않도록 Elevated,
Unelevated 및 보안 실검증 명령을 실행하지 않는다. 로그인 후 프로젝트를 선택하면
채팅이 바로 열린다. 대신 Codex가 실행하는 로컬 명령은 현재 로그인한 Windows
사용자의 권한으로 실행된다. 이 버전은 **Windows OS 수준 격리 환경이 아니다.**

## 처음 실행

1. ZIP과 같은 이름의 `.zip.sha256`을 함께 받아 SHA-256을 확인한다.
2. ZIP 전체를 현재 사용자가 쓸 수 있는 로컬 폴더에 압축 해제한다.
   `C:\Users\<사용자>\Downloads\HumanCodex`처럼 Downloads 안의 중첩 폴더도 된다.
   ZIP 안에서 직접 실행하거나 네트워크 공유에서 실행하지 않는다.
3. `Login-HumanCodex.bat`을 실행하고 회사가 허용한 ChatGPT 계정과 워크스페이스로
   로그인한다.
4. `Launch-HumanCodex.bat`을 실행한다.
5. 프로젝트 이름을 입력하고 **폴더 선택…**으로 작업할 폴더를 선택한다.
6. **새 채팅**을 누른다. 샌드박스 설치, UAC 승인, 47개 검사 대기는 없다.

설치 폴더와 프로젝트 폴더는 같은 드라이브에 있을 필요가 없다. C:의 여러 단계
아래에 설치하고 E:의 중첩 프로젝트를 선택해도 각 절대경로를 따로 연결한다.
드라이브 최상위 폴더만 지원하는 구조가 아니다.

앱 상태, 로그인, 로그, 암호화 vault와 Snapshot은
`<설치 폴더>\HumanCodexData`에 저장되고 앱 작업·임시 공간은
`<설치 폴더>\Workspace`에 저장된다. 사용자가 선택한 프로젝트는 원래 위치에서
작업한다. `HumanCodexData`에는 인증정보가 들어 있을 수 있으므로 공유하지 않는다.

## 직접 실행 모드의 보안 경계

- 프로젝트 선택, 프로젝트별 지침, 사용자 승인 화면, Snapshot/복구, 붙여넣은
  비밀값 탐지는 계속 동작한다.
- 위 기능은 작업 실수를 줄이는 제품 안전장치이며 OS 격리가 아니다.
- 현재 Windows 사용자가 읽거나 쓸 수 있는 다른 로컬 파일과 네트워크에 로컬 명령이
  접근하는 것을 운영체제 수준에서 막지 않는다.
- 작업할 자료만 선택한 프로젝트에 두고, 현재 사용자에게 열려 있는 다른 민감
  자료가 있는 PC에서는 사용 범위를 신중히 정한다.
- SmartScreen, AppLocker, WDAC, EDR 및 회사 네트워크 정책을 우회하지 않는다.

## 웹 검색

공개 웹 검색은 의도적으로 켜져 있다. 검색어와 대화에 포함한 내용은 Codex 서비스로
전송될 수 있으므로 회사 파일 원문, 내부 경로, 고객 식별자, 비밀값을 넣지 않는다.
Human Codex의 사전검사와 지침은 완전한 DLP를 보장하지 않는다.

정상 지원 범위는 채팅, 선택 프로젝트 읽기·쓰기, Git 작업, 자식 프로세스 작업,
Snapshot/복구, 승인 UI와 공개 웹 검색이다. 이 직접 실행 버전에서는 로컬 명령의
파일·네트워크 접근을 별도 샌드박스로 차단하지 않는다.

문서·프레젠테이션 등 Code Mode 기능에 필요한 `codex-code-mode-host.exe`를 현재
검증된 Codex 0.147.0 원본 배포와 같은 런타임 폴더에 포함한다. 파일이 없거나 실행되지 않으면
릴리스 검증이 실패한다.

## 스킬·자가수리·대화 편의 기능

- 회사 직접 모드는 선택 프로젝트뿐 아니라 설치 폴더도 진단·자가수리 대상으로
  사용할 수 있다. 따라서 ZIP은 현재 사용자가 쓸 수 있는 폴더에 풀어야 한다.
- 자가수리는 실행 중인 화면, Electron, Core, App Server를 종료하거나 재시작하지 않는다.
  소스·UI·설정 수리는 디스크에 저장한 뒤 사용자가 다음에 정상 실행할 때 적용한다.
  실행 중 잠긴 EXE나 런타임 변경은 핫 교체하지 않고 검증된 새 패키지로 교체한다.
- 사이드바의 **추가 스킬 관리**에서 일반 검색어만 입력해 OpenAI 공식 스킬과 공개
  GitHub 저장소의 실제 `SKILL.md` 폴더를 찾는다. GitHub `/tree/ref/path` 주소를 직접
  붙여 넣어도 된다.
- 설치된 스킬은 `HumanCodexData\codex-home\skills`에만 저장된다. 경로·파일 수·용량을
  검사하며 설치 중 외부 스크립트를 실행하지 않는다.
- 필요한 기능이 없으면 Codex가 공개 기능명으로 스킬을 찾아 자동 준비할 수 있다.
  프로젝트 내용·회사 내부 경로·고객 식별자를 검색어로 보내서는 안 된다.
- 실행 중 보낸 메시지는 현재 응답이 끝난 뒤 FIFO 순서로 자동 전송된다.
- 완료된 도구 기록은 해당 응답에 접히며, 완료 작업 카드가 하단에 누적되지 않는다.
- 완료된 채팅은 목록 우클릭 메뉴에서 삭제할 수 있다.

현재 Human Codex는 공개 문서와 도움말을 검색해 낯선 프로그램의 사용법을 파악할 수
있지만, 화면 클릭이 필수인 GUI 자동화는 **대화형 브라우저·컴퓨터 제어 비활성화** 범위에
남아 있다. 파일·코드·CLI·지원되는 문서 형식 작업과 같은 의미는 아니다.

릴리스 검증은 전체 파일 manifest, CycloneDX SBOM, 반복 ZIP의 SHA-256 일치,
Python/Codex/App Server/Code Mode Host/스킬 관리자/Electron/Core 실행 및 직접 실행
상태를 확인한다.
